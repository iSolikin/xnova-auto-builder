# XNOVA Auto Builder

**Планирование развития и ресурсов в XNOVA.** Расширение Chrome помогает выполнять повторяющиеся игровые действия по выбранной стратегии.

## Возможности

- Строит план развития зданий и исследований с учётом доступных ресурсов.
- Управляет излишками ресурсов на внутриигровом рынке по заданным правилам.
- Поддерживает отдельные сценарии для разведки, рейдов и экспедиций.
- Показывает состояние и действия в панели расширения.
