# XNOVA Auto Builder

Расширение для XNOVA, которое помогает развивать аккаунт по выбранному плану и использовать излишки ресурсов.

### Возможности

- Планирует постройки и исследования с учётом ресурсов и заданных приоритетов.
- Выставляет излишки на внутриигровом рынке по правилам владельца аккаунта.
- Поддерживает сценарии разведки, рейдов и экспедиций.
- Показывает текущий план и историю действий в панели расширения.
